# 音樂來源

背景音樂的「錄音」曲目來自 [OpenGameArt.org](https://opengameart.org)，授權皆為 CC0（公有領域，可自由使用，不需標示作者）。檔案已轉成單聲道 mp3 以縮小體積。

| 檔案 | 曲名 | 來源頁面 |
|---|---|---|
| haunted.mp3 | Haunted Beach | https://opengameart.org/content/haunted-beach |
| ambient.mp3 | ambient sound creepy | https://opengameart.org/content/ambient-sound-creepy |
| creepyloop.mp3 | Creepy Ambient Loop | https://opengameart.org/content/creepy-ambient-loop |

其餘曲風（陰森低鳴、迷霧、荒廢教堂、靜夜）與所有音效都是在瀏覽器裡即時合成，沒有使用音檔。
